# Task 4

#### 一、主要发展历史

由于**数据稀缺**和**物理环境的复杂性**，研究人员通常会针对特定任务单独训练一个模型

RT系列论文展示了一个全新的演进路线：构建一个**通用的机器人基础模型**

1.**RT-1**：验证了Transformer架构在物理世界实时控制中的有效性，首次提出了**动作分词**(Action Tokenization)的核心概念

2.**RT-2**：确立了 **VLA** (Vision-Language-Action，视觉-语言-动作) 范式，首次将机器人动作直接视为一种语言，使互联网海量多模态常识向机器人领域进行无缝迁移

3.**RT-X** ：验证了跨**机器人形态**（Cross-Embodiment）混合训练的可行性，打破了不同硬件实体的界限

#### 二、RT-1

#### 2.1 架构设计

- **视觉特征提取**：采用轻量高效的 EfficientNet 作为主干网络；**人话：看图像转换成向量**
- **条件指令融合**：使用 FiLM (Feature-wise Linear Modulation) 层。FiLM 可以利用文本指令的语义特征去动态调整视觉特征图的激活值，从而实现让视觉模型聚焦于指令相关目标的效果；**人话：计算注意力**

  **特征压缩与序列生成**：通过 Token Learner 模块压缩庞大的视觉特征图，然后输入到标准的自回归 Transformer 中，顺序预测动作；**人话：特征提取+预测出一个向量**

‍

#### 2.2 动作分词 (Action Tokenization) 机制

传统的模仿学习算法通常让神经网络去直接拟合（回归）一个连续的数值（例如机械臂每个关节的目标速度 -0.154 m/s 到 0.852 m/s）。由于连续数值的分布极难训练，RT-1 创新性地将这一过程变成了**离散的分类问题**：

**动作区间均匀划分**：将机械臂每个维度的动作范围（如 X、Y、Z 移动，夹爪开合等）均匀切分成 **256 个小区间（Bins）** [[1](https://www.google.com/url?sa=E&q=https%3A%2F%2Fgithub.com%2Fdatawhalechina%2Fevery-embodied%2Fblob%2Fmain%2F06-%25E7%25AD%2596%25E7%2595%25A5%25E6%258A%2593%25E5%258F%2596%25E6%2588%2596%25E6%258A%2593%25E5%258F%2596VLA%2F%25E5%25A4%25A7%25E6%25A8%25A1%25E5%259E%258B%25E6%258E%25A7%25E5%2588%25B6%25E3%2580%2581VLA%25E3%2580%2581VLM%2F03RT%25E7%25B3%25BB%25E5%2588%2597%25E8%25AE%25BA%25E6%2596%2587%25E8%25A7%25A3%25E8%25AF%25BB%25E4%25B8%258E%25E4%25BB%25A3%25E7%25A0%2581%25E5%2588%2586%25E6%259E%2590%2F01RT%25E7%25B3%25BB%25E5%2588%2597%25E8%25AE%25BA%25E6%2596%2587%25E8%25A7%25A3%25E8%25AF%25BB%25E4%25B8%258E%25E4%25BB%25A3%25E7%25A0%2581%25E5%2588%2586%25E6%259E%2590.md)]。  
**离散 Token 化**：任何一个连续的物理量，都会根据它所落入的区间，被映射为 0 到 255 之间的整数[[1](https://www.google.com/url?sa=E&q=https%3A%2F%2Fgithub.com%2Fdatawhalechina%2Fevery-embodied%2Fblob%2Fmain%2F06-%25E7%25AD%2596%25E7%2595%25A5%25E6%258A%2593%25E5%258F%2596%25E6%2588%2596%25E6%258A%2593%25E5%258F%2596VLA%2F%25E5%25A4%25A7%25E6%25A8%25A1%25E5%259E%258B%25E6%258E%25A7%25E5%2588%25B6%25E3%2580%2581VLA%25E3%2580%2581VLM%2F03RT%25E7%25B3%25BB%25E5%2588%2597%25E8%25AE%25BA%25E6%2596%2587%25E8%25A7%25A3%25E8%25AF%25BB%25E4%25B8%258E%25E4%25BB%25A3%25E7%25A0%2581%25E5%2588%2586%25E6%259E%2590%2F01RT%25E7%25B3%25BB%25E5%2588%2597%25E8%25AE%25BA%25E6%2596%2587%25E8%25A7%25A3%25E8%25AF%25BB%25E4%25B8%258E%25E4%25BB%25A3%25E7%25A0%2581%25E5%2588%2586%25E6%259E%2590.md)]。  
**Transformer 的天然兼容**：Transformer 本质上是一个分类预测器。将动作离散化后，**机械臂的控制任务被完美转化为了预测下一个动作单词的生成任务**

### 三、 RT-2(VLA范式)

#### 3.1 核心范式：动作即语言（Action as Language）

 RT-2 提出：**不再独立训练机器人模型，而是直接对一个已经学习了海量互联网图文常识的多模态大模型（VLM）进行微调，使其可以直接吐出机器人控制动作**。

- ​**统一的语言交互空间**​：  
  在 VLA 模型中，以下两个任务在模型内部是完全统一的[[1](https://www.google.com/url?sa=E&q=https%3A%2F%2Fgithub.com%2Fdatawhalechina%2Fevery-embodied%2Fblob%2Fmain%2F06-%25E7%25AD%2596%25E7%2595%25A5%25E6%258A%2593%25E5%258F%2596%25E6%2588%2596%25E6%258A%2593%25E5%258F%2596VLA%2F%25E5%25A4%25A7%25E6%25A8%25A1%25E5%259E%258B%25E6%258E%25A7%25E5%2588%25B6%25E3%2580%2581VLA%25E3%2580%2581VLM%2F03RT%25E7%25B3%25BB%25E5%2588%2597%25E8%25AE%25BA%25E6%2596%2587%25E8%25A7%25A3%25E8%25AF%25BB%25E4%25B8%258E%25E4%25BB%25A3%25E7%25A0%2581%25E5%2588%2586%25E6%259E%2590%2F01RT%25E7%25B3%25BB%25E5%2588%2597%25E8%25AE%25BA%25E6%2596%2587%25E8%25A7%25A3%25E8%25AF%25BB%25E4%25B8%258E%25E4%25BB%25A3%25E7%25A0%2581%25E5%2588%2586%25E6%259E%2590.md)]：

  - **传统 VQA 任务**：输入：图像 + 提示词“这是什么？”->型输出文本 Token："Apple"。
  - **机器人控制任务**：输入：图像 + 提示词“把苹果捡起来”->模型输出文本 Token："128 128 100 1 0..."。  
    系统会把大模型预测生成的这组数字 Token 拦截下来，自动还原为机械臂的控制信号

‍

#### 3.2 语义推理与涌现能力 (Emergent Capabilities)

RT-2 展现出了以往任何机器人模型都不具备的**常识泛化与物理推理能力**

**符号与抽象理解**：对机器人说帮我把可乐罐放到泰勒·斯威夫特的照片上，机器人能在多张照片中准确挑出泰勒的照片。  
**逻辑推理（符号推理）** ：输入指令捡起快灭绝的动物，哪怕训练数据中**从来没有**关于灭绝动物的抓取记录，RT-2 也能通过脑中的背景知识，推理出恐龙属于灭绝动物，进而精准把机械臂移向恐龙塑料玩具[[1](https://www.google.com/url?sa=E&q=https%3A%2F%2Fgithub.com%2Fdatawhalechina%2Fevery-embodied%2Fblob%2Fmain%2F06-%25E7%25AD%2596%25E7%2595%25A5%25E6%258A%2593%25E5%258F%2596%25E6%2588%2596%25E6%258A%2593%25E5%258F%2596VLA%2F%25E5%25A4%25A7%25E6%25A8%25A1%25E5%259E%258B%25E6%258E%25A7%25E5%2588%25B6%25E3%2580%2581VLA%25E3%2580%2581VLM%2F03RT%25E7%25B3%25BB%25E5%2588%2597%25E8%25AE%25BA%25E6%2596%2587%25E8%25A7%25A3%25E8%25AF%25BB%25E4%25B8%258E%25E4%25BB%25A3%25E7%25A0%2581%25E5%2588%2586%25E6%259E%2590%2F01RT%25E7%25B3%25BB%25E5%2588%2597%25E8%25AE%25BA%25E6%2596%2587%25E8%25A7%25A3%25E8%25AF%25BB%25E4%25B8%258E%25E4%25BB%25A3%25E7%25A0%2581%25E5%2588%2586%25E6%259E%2590.md)]。

‍

#### 3.3 联合微调 (Co-fine-tuning)

如果让大模型只在机器人轨迹数据上进行微调，模型会在短时间内遗忘其原本拥有的常识和逻辑，变成一个只会控制机械臂的傻瓜。这种现象被称为**灾难性遗忘**。

- **解决策略**：RT-2 将机器人操作数据与海量的原始互联网视觉问答（VQA）数据以一定的比例混合，进行**联合微调（Co-fine-tuning）** ，从而完美保留了大模型的推理智商，又让其掌握了精准控臂的技能。

### 四、 RT-X：解决身体多样性

如何用一个大脑，去控制不同的身体？这就是 **RT-X** 的使命

‍

#### 4.1 Open X-Embodiment 数据集

Google 联合全球 33 家顶尖机器人实验室，构建了一个名为 **Open X-Embodiment** 的超级具身智能混合数据集，其中涵盖了 22 种不同形态的机械臂（如 Franka、UR5、WidowX 等）的演示轨迹

‍

#### 4.2 正向迁移 (Positive Transfer) 现象

不同形态的机器人如何使用同一套数据格式训练？

- **统一动作空间**：RT-X 将所有不同形态机器人的动作信号，统一转换并映射到标准的 **7-DoF（3维平移 + 3维旋转姿态 + 1维夹爪开合）**  空间中。

  DoF：Degrees of Freedom
- **混合训练奇迹**：实验结果发现，在海量不同硬件形态的数据混合训练下，模型在某一个特定机械臂上表现出的性能，居然超越了只用该特定机械臂单一数据训练的结果（即 **Positive Transfer / 正向迁移**）。特别是在某些数据极度稀缺的任务上，机械臂能从别人的训练数据里举一反三，学会新动作
